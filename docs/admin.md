# Grok2API 管理面板指南
 
 Grok2API 提供了一个功能强大的 Web 管理后台，用于管理 Token、配置系统参数以及监控服务状态。
 
 ## 访问方式
 
 - **地址**：`http://<您的服务器IP>:8000/admin`
 - **默认密码**：`grok2api`
   > 建议在 `data/config.toml` 或环境变量 `app_key` 中修改默认密码。
 
 ---
 
 ## 功能详解
 
 ### 1. Token 管理 (Token Management)
 
在此页面，您可以添加、查看和管理所有的 Grok 账号 Token。
 
 #### 批量导入
支持强大的批量导入功能，点击右上角 **“导入”** 按钮即可使用。
 
 - **普通导入**：直接粘贴 Token，一行一个。
 - **自定义格式导入**：
   如果您的数据格式为 `email----password----token` 或其他自定义分隔符，可以在导入弹窗中指定：
   - **分隔符**：例如 `----`
   - **索引值**：例如 `2`（表示取第3部分，从0开始计数）
 
   *示例：对于数据 `user@Gmail.com----123456----eyJs...`，设置分隔符为 `----`，索引值为 `2`，即可自动提取出 `eyJs...`。*
 
 #### 状态筛选与监控
 - **正常 (Active)**：Token 可用，额度充足。
 - **限流 (Cooling)**：Token 暂时被 Grok 官方限制，处于冷却中（系统会自动在此期间不分配任务）。
 - **失效 (Invalid)**：Token 已过期或无效。
 
 #### 批量操作
 页面底部提供批量操作栏（选中 Token 后出现）：
 - **刷新**：强制刷新选中 Token 的状态和剩余额度。
 - **导出**：导出选中 Token 到文件。
 - **NSFW**：批量开启 Unhinged 模式（解除安全限制，需配置代理）。
 - **删除**：批量删除 Token。
 
 ---
 
 ### 2. 配置管理 (Configuration)
 
在此页面可以实时修改系统配置，无需重启 Docker 容器。
 
 #### 核心配置
 - **Server URL**：设置服务的外部访问地址。
 - **API Key / App Key**：修改系统访问密钥。
 
 #### 许可证 (License)
 - **许可证书**：填入您的 License Key。
 - **许可证加密锁**：填入 License Secret（用于解密证书）。
 - **状态显示**：输入后会自动验证并显示有效期。
 
 #### 其他设置
 - **Network**：配置代理 (Proxy) 和超时时间。
 - **Chat**：开启/关闭思维链、流式响应等。
 - **Image**：配置图片生成参数和 WebSocket 直连模式。
 
 ---
 
 ### 3. 缓存管理 (Assets)
 
 - **清理缓存**：一键清理服务器上存储的临时图片/视频文件，释放磁盘空间。
 - **自动清理**：可在配置中设置自动清理策略（例如超过 1GB 自动删除旧文件）。

---

### 4. 许可证管理 (License Management)

如果您是私有化部署的管理员或服务提供商，可能会遇到许可证过期续费的问题。

#### 一般用户（被授权方）
当您的许可证即将到期或已经过期时：
1.  联系您的服务提供商获取新的 **许可证书 (License Key)**。
    *   *注意：如果服务商同时也更改了加密锁，您也需要获取新的 **许可证加密锁 (License Secret)**。*
2.  登录管理面板 -> **配置管理**。
3.  在 **License** 区域，删除旧的证书内容，填入新的证书。
4.  输入框下方会自动显示新的有效期（例如 `✅ 有效 (有效期至: 2026-12-31)`）。
5.  点击页面底部的 **保存配置** 按钮。

#### 服务提供商（授权方）
如果您持有源码并负责分发许可证，请使用 `scripts/gen_license.py` 工具生成新的 Key。

**生成步骤**：
1.  确保您的环境中已安装 Python 依赖。
2.  确保 `data/config.toml` 中配置了您的私有 `license_secret`。
3.  运行生成脚本：
    ```bash
    # 语法：python scripts/gen_license.py <授权IP> [有效期天数]
    
    # 示例：为 IP 1.2.3.4 生成一个有效期 30 天的证书
    python scripts/gen_license.py 1.2.3.4 30
    
    # 示例：生成永久证书
    python scripts/gen_license.py 1.2.3.4
    ```
4.  将生成的 Key 发送给用户即可。

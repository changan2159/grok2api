# 许可证续费与延期说明

## 原理解析

由于 Grok2API 的许可证书（License Key）采用了 **Fernet 对称加密** 算法，证书内部包含了生成时间 (`created_at`) 和有效期 (`exp`)。

一旦证书生成，其内容即被加密固定。**因此，无法直接在原有的证书字符串上进行“续期”修改。**唯一的续费方式是**为原来的 IP 地址重新生成一个新的、有效期更长的证书**，并替换掉旧证书。

## 续费操作流程

如果您需要为之前的许可证续费（例如从 30 天延长到 365 天），请按照以下步骤操作：

### 方式一：基于旧证书续费（推荐）

如果您只有旧的 License Key，可以直接基于它生成一个新的续期证书，原有 IP 等信息保持不变。

**命令语法**：
```bash
python scripts/gen_license.py renew <旧LicenseKey> [续费天数]
```

**示例**：
```bash
# 将旧证书有效期延长 30 天
python scripts/gen_license.py renew gAAAAABk... 30

# 将旧证书转为永久有效
python scripts/gen_license.py renew gAAAAABpiEzodOJuCWqfc6PgqJLRzcAgP84eclR4H-WP74KEFIphSbaRpd-U6gVqrDL4mWeBIB_i1p8w1-QpROyGasu3LBc5H15WEskPkUdPj71uFDfrS1YtR4V8MiXahR7UwuVF6EmkIdiNENfawaWqnVGjomGqrcDHPOO09S2fHZ5O3Yx0A4Vg-4uyhvdDaGf0BA_Mq5XY
```

### 方式二：生成新证书（覆盖）

如果您丢失了旧证书，或者想彻底更换授权信息，可以为该 IP 生成全新的证书。

**命令语法**：
```bash
python scripts/gen_license.py <IP地址> [有效期天数]
```

### 3. 应用新证书
无论使用哪种方式生成的 Key，都是**新的字符串**。
1.  即刻将生成的 **新 License Key** 发送给用户。
2.  让用户登录管理面板 -> **配置管理** -> **License**。
3.  填入新 Key 并保存。

## 常见问题

**Q: 旧证书没到期，换了新证书会怎么样？**
A: 旧证书会立即失效（被新证书替换）。新证书的有效期将完全覆盖旧证书，系统只认当前配置中填写的那个证书。

**Q: 是否需要更换加密锁 (License Secret)？**
A: 不需要。只要您的 `config.toml` 中的 `license_secret` 没有变更，您生成的任何新证书都可以直接被用户识别和使用。
